# AgentShield

## Trust & Reliability Layer for Agentic Commerce

> AI can propose. Deterministic systems authorize. Razorpay executes.

AgentShield is an AI-agent safety layer for agentic commerce.

It validates financial actions before they can reach Razorpay, enforcing merchant-defined policies, approval requirements, financial verification, duplicate protection, and auditability.
